# Atharva Deshmukh Portfolio

Responsive React + Vite portfolio inspired by your cinematic mountain hero reference.

## Run locally
1. Install Node.js 18+.
2. Extract this ZIP and open a terminal in the project folder.
3. In Command Prompt, run `npm install` then `npm run dev`. In PowerShell, use `npm.cmd install` then `npm.cmd run dev`.
4. Open the local URL printed by Vite.

## Build for hosting
Run `npm run build` (or `npm.cmd run build` in PowerShell); upload the contents of `dist/` to your static hosting provider.

## Before publishing
Update the sample project cards, replace `atharva@example.com`, add your real social links, and connect the resume button to your PDF. The portrait is a cutout of your photo, not a true 3D mesh.
